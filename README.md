Emberwatch, a tower defense where you defend the last ember lantern in a dusk garden against waves of shadow wisps across 10 waves, with 4 tower types, 5 enemy types, upgrades, selling, and a boss on wave 10.

## How to play

- **Mouse:** Click build plots to place selected towers, click placed towers to inspect, upgrade, or sell.
- **Keys 1 - 4:** Select tower type (1: Ember Cannon, 2: Frost Spire, 3: Storm Bell, 4: Thorn Snare).
- **SPACE / Enter:** Start the next wave / Begin game.
- **P / ESC:** Pause or resume game.
- **U:** Upgrade selected tower.
- **X:** Sell selected tower.
- **R:** Restart game.
- **M:** Toggle audio mute.

## Run it

```sh
node serve.ts
```
